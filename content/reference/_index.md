Conjugation tables, pronoun charts, vocabulary lists, and grammar facts, described plainly
and consistently.

Reference is for **looking things up** while you work. It describes the language and
nothing more — no lessons, no arguments, no advice. For the reasoning behind a rule, see
the [explanation](/explanation/) section.
