**poder** — can; to be able to

Irregular in three separate ways. The presente simple is stem-changing: `o` becomes `ue`
in every form except nosotros and vosotros, which keep `pod-`. The pretérito indefinido is
built on the irregular stem `pud-`. The futuro simple uses a shortened stem `podr-` rather
than the full infinitive. Only the pretérito imperfecto is regular.

The gerundio is `pudiendo`, with the same `o` to `u` shift seen in the pretérito.

## Presente simple

| Sujeto | Verbo | Ejemplo |
| --- | --- | --- |
| yo | puedo | Yo puedo hablar español. |
| tú | puedes | Tú puedes correr rápido. |
| él / ella | puede | Él puede venir hoy. |
| nosotros | podemos | Nosotros podemos ayudar. |
| vosotros | podéis | Vosotros podéis entrar ahora. |
| ellos | pueden | Ellos pueden trabajar juntos. |

## Presente continuo (progresivo)

Uncommon. These forms are grammatical, but *poder* is rarely used in the progressive.

| Sujeto | Verbo | Ejemplo |
| --- | --- | --- |
| yo | estoy pudiendo | Yo estoy pudiendo dormir mejor. |
| tú | estás pudiendo | Tú estás pudiendo caminar más. |
| él / ella | está pudiendo | Ella está pudiendo trabajar hoy. |
| nosotros | estamos pudiendo | Nosotros estamos pudiendo avanzar. |
| vosotros | estáis pudiendo | Vosotros estáis pudiendo ayudar. |
| ellos | están pudiendo | Ellos están pudiendo estudiar más. |

## Futuro simple

| Sujeto | Verbo | Ejemplo |
| --- | --- | --- |
| yo | podré | Yo podré venir mañana. |
| tú | podrás | Tú podrás hablar con Ana. |
| él / ella | podrá | Él podrá trabajar mañana. |
| nosotros | podremos | Nosotros podremos ayudar. |
| vosotros | podréis | Vosotros podréis entrar después. |
| ellos | podrán | Ellos podrán venir mañana. |

| Sujeto | Verbo | Ejemplo |
| --- | --- | --- |
