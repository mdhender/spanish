**correr** — to run

A fully regular `-er` verb. Every form below follows the standard pattern, so *correr* is
a useful model for the whole class: replace the stem `corr-` and the endings carry over.

## Presente simple

| Sujeto | Verbo | Ejemplo |
| --- | --- | --- |
| yo | corro | Yo corro en el parque. |
| tú | corres | Tú corres cada mañana. |
| él / ella | corre | Él corre con su perro. |
| nosotros | corremos | Nosotros corremos juntos. |
| vosotros | corréis | Vosotros corréis por la ciudad. |
| ellos | corren | Ellos corren en la playa. |
