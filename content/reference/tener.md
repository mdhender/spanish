**tener** — to have

Irregular in three separate ways, like [poder](../poder/). The presente simple is doubly
irregular: the yo form takes `-go` (`tengo`), and `e` becomes `ie` in tú, él/ella, and
ellos, while nosotros and vosotros keep `ten-`. The pretérito indefinido uses the stem
`tuv-`. The futuro simple uses `tendr-`, with a `d` that appears from nowhere. Only the
pretérito imperfecto is regular.

The `-uv-` pretérito indefinido is shared with [andar](../andar/) and [estar](../estar/):
`anduve`, `estuve`, and `tuve` take one identical set of endings (`-e`, `-iste`, `-o`,
`-imos`, `-isteis`, `-ieron`). Learn one and the other two follow.

## Presente simple

| Sujeto | Verbo | Ejemplo |
| --- | --- | --- |
| yo | tengo | Yo tengo un libro. |
| tú | tienes | Tú tienes una pregunta. |
| él / ella | tiene | Él tiene un perro. |
| nosotros | tenemos | Nosotros tenemos tiempo. |
| vosotros | tenéis | Vosotros tenéis una casa. |
| ellos | tienen | Ellos tienen dos coches. |

## Presente continuo (progresivo)

Uncommon. These forms are grammatical, but *tener* is rarely used in the progressive.

| Sujeto | Verbo | Ejemplo |
| --- | --- | --- |
| yo | estoy teniendo | Yo estoy teniendo un buen día. |
| tú | estás teniendo | Tú estás teniendo un problema. |
| él / ella | está teniendo | Ella está teniendo una reunión. |
| nosotros | estamos teniendo | Nosotros estamos teniendo una conversación. |
| vosotros | estáis teniendo | Vosotros estáis teniendo una buena semana. |
| ellos | están teniendo | Ellos están teniendo dificultades. |

## Futuro simple

| Sujeto | Verbo | Ejemplo |
| --- | --- | --- |
| yo | tendré | Yo tendré tiempo mañana. |
| tú | tendrás | Tú tendrás una respuesta mañana. |
| él / ella | tendrá | Él tendrá un coche nuevo. |
| nosotros | tendremos | Nosotros tendremos una reunión. |
| vosotros | tendréis | Vosotros tendréis más tiempo. |
| ellos | tendrán | Ellos tendrán una casa nueva. |

## Pretérito indefinido

| Sujeto | Verbo | Ejemplo |
| --- | --- | --- |
| yo | tuve | Yo tuve una reunión ayer. |
| tú | tuviste | Tú tuviste una pregunta. |
| él / ella | tuvo | Él tuvo un problema ayer. |
| nosotros | tuvimos | Nosotros tuvimos tiempo. |
| vosotros | tuvisteis | Vosotros tuvisteis una buena idea. |
| ellos | tuvieron | Ellos tuvieron mucho trabajo. |
